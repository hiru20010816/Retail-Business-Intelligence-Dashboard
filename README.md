# Retail Business Intelligence & Sales Performance Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyse retail sales performance, profitability, product demand, and regional performance using a fictional Sri Lankan retail dataset.

## Objectives
- Monitor key sales and profitability KPIs.
- Analyse sales trends over time.
- Compare product category and regional performance.
- Understand revenue distribution across sales channels.
- Support data-driven business decisions.

## Tools & Technologies
- Microsoft Power BI
- Power Query (ETL)
- DAX
- Excel

## Key Features
- Interactive KPI cards
- Dynamic slicers for Month, Region, Sales Channel, and Product Category
- Sales trend analysis
- Regional profit analysis
- Product category analysis
- Sales channel analysis

## Data Model
A star-schema model consisting of:
- Fact table: SalesData
- Dimension tables: DateTable, ProductTable, RegionTable

## Dataset
The project uses 300 fictional retail sales records. All data is synthetic and intended for demonstration and learning purposes.
